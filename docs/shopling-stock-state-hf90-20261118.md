# Shopling 재고상태 HF90 — 정확 팝업 소유권 영수증 연결

## 실제 증상

- HF89(v0.6.52)에서 Shopling 파란 전송 버튼이 눌리고 전송 화면도 열렸다.
- 그러나 Commerce OS는 `성공 0/1건 · 실패·확인 필요 1건`으로 끝났다.
- 외부 전송 뒤 성공 영수증을 놓친 상태이므로 같은 B코드 자동 재시도는 중복 전송 위험이 있다.

## 원인

HF89는 새 A21 전송 팝업을 자체 영수증에는 기록했지만, 기존에 검증된 HF60/HF72 결과 감시기가 읽는 `active.workTabs.A21_POPUP`에는 파란 버튼 클릭 전에 기록하지 않았다. 그 결과 Shopling 처리·결과 화면이 실제로 시작돼도 Commerce OS가 해당 작업 소유 팝업으로 귀속하지 못할 수 있었다.

## HF90 변경

- 버전: `0.6.53`
- 백그라운드: `background-v099.js`
- 정확한 A21 팝업 URL과 opener/A21 목록 소유권을 다시 확인한다.
- 파란 전송 버튼 호출 전에 정확 팝업을 `active.workTabs.A21_POPUP`에 저장한다.
- 전송 호출이 확인되면 외부 쓰기 완료·자동 재시도 금지 영수증을 저장한다.
- 기존에 검증된 HF60/HF72 처리·결과 화면 감시 경로가 같은 팝업 소유권을 이어받게 한다.

## 남은 검증

실제 Shopling 외부 전송은 사용자가 선택한 안전한 B코드 1건으로 검증해야 한다. 다음 조건을 모두 만족하기 전에는 완전 성공으로 판정하지 않는다.

1. Shopling 전송이 한 번만 실행된다.
2. Commerce OS가 `Shopling 전송 접수 완료 1/1건`으로 끝난다.
3. 성공 건에 재시도 버튼이 표시되지 않는다.
4. 재전송 목록 상태가 `이번 전송 완료`로 바뀐다.

기존 HF89에서 전송 화면까지 간 미확정 건은 Shopling 실제 상태를 확인하기 전 재시도하지 않는다.
