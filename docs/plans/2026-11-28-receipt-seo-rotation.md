# 6단계 ③ 입고건 SEO 대량등록·물갈이 상시 편입

이번 차시에 입고를 확정하면 해당 B코드를 물갈이 관리 대상에 자동으로 기록한다. SEO 등록 준비 상태와 물갈이 편입 상태는 따로 추적한다.

1. **대상 확정** — 입고 수량이 양수인 B코드를 기존 SEO 상품 카드와 연결한다. 같은 상품의 옵션은 하나의 등록 작업으로 묶고, 카드 연결이 모호하면 해당 B코드와 사유를 남긴다.
2. **SEO 대량등록** — 가격과 판매중 전송 결과, SEO 자료를 확인한 상품부터 기존 대량등록 대기열로 보낸다. 가격 유지도 정상 결과로 인정한다. 기존 상품의 마켓별 등록 이력을 대조해 필요한 등록만 진행하고, 재입고나 재실행 때 중복 등록을 막는다.
3. **물갈이 상시 편입** — 재입고 상품은 기존 관리 기록에 연결해 노출 기간·판매 이력·회차를 이어간다. SEO 자료 또는 마켓 자리가 부족해도 대상 기록을 유지하고, 준비되면 기존 물갈이 기준에 따라 이어간다.
4. **화면과 검증** — 6단계에서 B코드별 SEO 등록 결과, 물갈이 편입 상태, 보류 사유를 함께 표시한다. 11월 차시의 입고확정 후 미리보기로 온돌패스 수량과 대조하고, 신규·재입고·복수 옵션·자료 누락·재실행 사례에서 누락과 중복을 검증한다.

## 구현과 검증 기록

- Ops Center에 입고확정하면 해당 차시가 자동 편입된다. 이전에 마감한 차시는 원장과 마켓 이력을 조회할 수 있다.
- 6단계와 기존 SEO 자동운영에서 동일한 상품·회차를 사용한다. 보류 중인 옵션도 대상 목록에서 확인할 수 있다.
- 휴지 후 재등록은 삭제 확인, 새 상품코드 6개, 마켓 전송 접수, 실제 노출 확인을 거쳐 기존 회차를 이어간다. 회차 변경과 이력 저장은 하나의 트랜잭션에서 처리한다.
- 검증은 실제 React 화면의 다중 옵션·새로고침·중복 클릭, 등록 한도 경합, 부분 전송과 회차 전환을 포함한다. 11월 차시는 운영 입고확정 후 실제 수량을 확인한다.
