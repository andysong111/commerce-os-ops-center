# 발주차시 4단계 입고 화면 연결

## 목표

3단계 바코드 업무 종결 뒤 활성화된 4단계에서 실제 입고수량 입력 화면으로 바로 이동하고, 전량 입고 뒤 5단계 배송대행 실제비용·원가 입력으로 이어지게 한다.

## 수락 기준

- 실제 주문원장의 `orderedQuantity`를 입고 화면 노출 기준으로 사용한다.
- 저장 Draft의 주문수량 스냅샷이 오래됐어도 실제 주문원장에 주문 근거가 있으면 입고 입력판을 표시한다.
- 4단계 버튼은 같은 발주차시의 입고 입력판으로 이동한다.
- 미입고가 있으면 입고 입력판을 처음부터 열어 수량을 바로 입력할 수 있다.
- 전량 입고 뒤 5단계 버튼은 같은 입력판의 배송대행 실제비용·원가 입력으로 이동한다.
- 예약만 있고 실제 주문이 없는 줄은 입고 대상으로 표시하지 않는다.
