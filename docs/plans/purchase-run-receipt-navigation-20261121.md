# 발주차시 4단계 입고 화면 연결

## 목표

3단계 바코드 업무 종결 뒤 활성화된 4단계에서 실제 입고수량 입력 화면으로 바로 이동하고, 전량 입고 뒤 5단계 배송대행 실제비용·원가 입력으로 이어지게 한다.

## 수락 기준

- 정상 차시는 실제 주문원장의 `orderedQuantity`를 입고 화면 노출 기준으로 사용한다.
- 과거 차시처럼 ORDERED 전환만 빠진 경우에는 완료된 바코드 근거와 실제 1688 결제 품목·B-code·수량을 전부 대조한 뒤에만 입고 입력판을 복구한다.
- 예약수량과 실제 결제수량이 다르면 실제 결제수량을 입고 기준으로 사용하고, 최초 입고확정 이벤트에서 미구매 예약 차이를 취소수량으로 함께 원장화한다.
- 4단계 버튼은 같은 발주차시의 입고 입력판으로 이동한다.
- 미입고가 있으면 입고 입력판을 처음부터 열어 수량을 바로 입력할 수 있다.
- 전량 입고 뒤 5단계 버튼은 같은 입력판의 배송대행 실제비용·원가 입력으로 이동한다.
- 예약만 있고 실제 주문이 없는 줄은 입고 대상으로 표시하지 않는다.

## 안전 경계

페이지 열기와 4단계 이동은 읽기 전용이다. 사용자가 기존 입고확정 버튼을 눌렀을 때만 검증된 실제 결제수량과 미구매 예약 차이를 입고 이벤트 하나에 함께 기록한다. Product Master 재고, Shopling 판매상태, 실제 원가 저장도 기존 확인 버튼을 누르기 전에는 실행하지 않는다.
