# 발주차시 3단계 바코드 업무 종결

## 목표

서버 문서 보관함에서 최종 바코드 작업 파일 한 건을 선택해 현재 발주차시의 완료 근거로 확정하고, 발주차시 화면의 3단계를 완료·4단계를 활성 상태로 전환한다.

## 수락 기준

- 실제 주문이 기록된 정확한 발주 Draft에서만 종결할 수 있다.
- 서버 문서 보관함의 파일 한 건을 체크박스로 선택해야 한다.
- 선택 파일은 품목이 존재하고 모든 품목의 Product Master/B-code 매칭이 끝난 파일이어야 한다.
- 완료 원장은 Draft ID, 발주월, 서버 파일 ID, 신청번호, 파일 갱신시각, 품목/매칭 수, 파일 내용 SHA-256을 함께 저장한다.
- 같은 파일의 중복 요청은 기존 완료 원장을 재사용하고, 다른 파일로 덮어쓰기는 차단한다.
- 완료 뒤 발주차시 화면에서 3단계는 완료, 4단계는 입고 진행 상태가 된다. 새로고침 후에도 유지된다.
- 발주차시가 아닌 일반 바코드 작업에서는 종결 체크박스와 버튼을 노출하지 않는다.
