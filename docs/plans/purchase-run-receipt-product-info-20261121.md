# 발주차시 4단계 상품정보 표시 개선 (2026-11-21)

## 목표

- 3단계에서 확정한 서버 바코드 파일을 4단계 입고 화면의 상품정보 원본으로 사용한다.
- B-code별 실주문·입고 수량과 함께 모델번호, 모델명, 옵션, 상품 이미지를 즉시 표시한다.
- 시간 제한이 걸린 별도 상품 조회를 확정 파일에 정보가 없는 품목에만 실행한다.
- 조회가 끝나도 계속 보이던 `상품정보 확인 중` 문구를 제거하고 확정적인 빈 상태를 표시한다.

## 완료 기준

- 완료 파일의 불변 해시 검증을 통과한 행만 입고 상품정보로 사용한다.
- 같은 B-code가 여러 행이면 수량은 합산하고 상품정보는 첫 번째 유효값을 유지한다.
- 외부 이미지는 기존 허용 호스트 프록시를 통해 지연 로딩하며 실패하면 `이미지 없음`으로 대체한다.
- 기존 4단계 수량·부분입고·확정 로직과 5단계 실제비용 입력은 회귀하지 않는다.
- 관련 단위 테스트, 타입 검사, 린트, 빌드, 배포 화면 검증을 통과한다.

## 진행 기록

- [x] 확정 바코드 파일에 모델번호·모델명·옵션·이미지 URL을 입고 근거로 포함
- [x] 입고 워크스페이스에서 확정 파일 정보를 최우선으로 병합
- [x] 상품정보가 빠진 B-code에만 기존 보조 조회 실행
- [x] 4단계 표에 64×64 이미지와 명시적인 모델정보 표시
- [ ] 자동 테스트 및 배포 화면 검증
