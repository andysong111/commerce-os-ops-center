# AI 사우루스 상세페이지 일괄 제작 준비

## 운영 버전 확인

2026-11-26 기준 AI 사우루스 운영 배포는 커밋 `3079c395`를 사용했다. 엔진 기준은 `v260807-saas-launch-v1`이고, 배포된 1688 Importer는 `0.4.58`이다. 실제 연동을 활성화할 때는 준비 단계에서 확인한 버전 번호 대신 AI 사우루스 운영 배포의 현재 릴리스를 매 실행과 재시도 시점에 조회한다. 기존 OPS 상세페이지 Studio는 별도 서비스다. [운영 상태](https://ai-saurus.com/api/saas/health) · [Importer 매니페스트](https://ai-saurus.com/extension/manifest.json)

## 준비 단계 범위

- 상품출시 진행관리에서 선택한 1~20개 상품의 제작용 또는 공통 1688 링크와 판매 옵션을 OPS 작업판으로 가져온다. 상품별 옵션 선택, 직접 편집, 선택 상품 일괄 입력을 지원한다.
- 수정된 옵션을 OPS 작업 원장에 저장하고 연결 대기, 1688 로그인 대기, 제작 중, 승인 대기, 실패, 승인 완료를 표시할 구조를 둔다. 새 상품 선택은 정확한 상품 ID로만 가져오며 동일 선택은 작업을 재사용한다.
- 준비 API는 시작, 결과 수신, 재시도, 승인을 거부한다. 운영 DB 원장 설치와 웹 배포는 별도 적용 단계다.

## 실제 연결 검증

1. AI 사우루스 웹 화면과 같은 운영 제작 진입점에서 현재 배포, 엔진, 배포 Importer, 호스팅 원점, 호환 계약을 확인한다. 최신 배포에서 계약을 사용할 수 없으면 해당 실행을 보류한다.
2. 같은 Chrome 프로필의 운영 Importer에서 그 상품의 1688 로그인 상태를 확인한다. 비밀번호와 1688 쿠키는 OPS로 가져오지 않는다.
3. 확인된 상품·옵션·릴리스·브라우저 증거를 실행 식별자에 묶는다. 비용 승인과 작업별 재시도 한도를 검증하고, 실패 후 재시도 전 기존 요청과 비용의 최종 상태를 원장으로 대조한다.
4. 인증된 작업자가 검수 결과·파일 해시·호스팅 전송·실제 비용 영수증을 읽는다. 작업판에서 선택한 성공 품목을 승인하면 현재 상품 입력과 기존 이미지 주소를 다시 대조하고, `detailPageAsset.detailImageUrl`에 승인된 최종 호스팅 주소만 갱신한다. 실제 적용 시 선택 상품만 원자적으로 갱신하고 저장 결과를 다시 읽은 뒤 승인 완료로 표시한다.
5. 실제 연결은 한 상품에서 기존 AI 사우루스 화면과 결과, 1688 로그인, 영수증, 단일 URL 되읽기를 대조한 후 여러 상품으로 확대한다. 준비 단계의 모의 결과는 실사용 품질이나 비용의 근거가 아니다.
