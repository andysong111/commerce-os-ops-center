# 1688 결제 완료 내역 대조

- 목표는 발주차시의 1688 결제 증빙을 자동 대조해 운영자의 비용 입력을 배송대행 최종 청구액으로 줄이는 것이다.
- 발주차시에서 확정된 바코드 원본의 주문번호·B코드·수량으로 범위를 고정한다. 주문취소와 재주문은 원본 주문번호로 식별한다. 바코드 원본에 남은 주문이 취소됐거나 새 주문번호가 아직 연결되지 않았으면 저장을 보류한다.
- 11월 4일 차시는 5-4 결제 직전 근거 56건이 바코드 원본 58건에 포함된다. 나머지 두 주문은 주문 상세에서 품목·옵션·수량을 확인한 뒤 연결해야 한다.
- 2026년 7월 1688 결제 내보내기 보관본은 주문번호·실결제 금액·환불 상태·환불 금액을 제공한다. 품목·옵션·수량은 별도 주문 상세나 기존 5-4 자료를 사용한다. 현재 차시 원본의 형식과 범위를 확인한 뒤 읽기와 매핑을 연결한다.
- 운영자는 파일 업로드 대신 업무센터 5-5와 입고 화면 안내를 선택했다. 브라우저가 구매 작업대 접근을 차단했으므로 구매계정의 공식 조회 권한을 사용한다. 공식 조회는 확정 바코드의 주문번호만 요청한다.
- 5-5는 공식 구매자 조회로 결제 상태·상품·옵션·수량을 대조한다. 공급자 API의 주문 총액은 결제 예정액으로 설명된다. 실결제액 근거를 확인하기 전에는 자동 저장을 활성화하지 않는다.
- 서버에 주문별 실결제 합계와 취소·누락·중복 검증을 연결했다. 기존 금액 스냅샷과 중복 차감 방지 경로를 사용한다. 실제 계정의 조회 권한과 실결제 금액 원본 확인 후 배포한다.
