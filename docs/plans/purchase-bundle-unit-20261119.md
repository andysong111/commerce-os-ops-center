# B코드 소분단위 발주 규칙 · 2026-11-19

## 목표

배대지 바코드 작업에서 입력한 B코드별 소분단위를 상품마스터 SKU 원장에 보존하고, 이후 발주안 자동 생성과 모든 수동 수량 변경에 같은 기준을 사용한다. 실제 1688 주문·결제는 이 기능의 범위가 아니다.

## 확정 규칙

- 원장값: `skus.bundle_unit`, 최신 입력 우선 시각: `skus.bundle_unit_updated_at`.
- 자동 발주: 권장수량을 가장 가까운 유효 소분단위로 반올림한다. 정확히 절반이면 올림한다. 예: 단위 10에서 13→10, 15→20, 16→20.
- 박스입수량도 있으면 소분단위와 박스입수량의 최소공배수를 최종 주문단위로 사용한다.
- 양수 권장수량은 최소 한 단위를 주문하며, 예산·SKU별 최대수량을 넘으면 임의로 단위를 깨지 않고 해당 행을 제외하거나 차단한다.
- 수동 추가·수량변경은 자동 보정하지 않는다. 정확한 배수가 아니면 `이 상품은 소분단위가 N개입니다.`를 표시하고 저장을 차단한다.
- 아직 원장값이 없는 기존 B코드는 기존 발주 호환을 위해 5개 단위를 사용한다. 새 값이 저장되면 즉시 원장값이 우선한다.

## 수락 기준

- 행복경로: 단위 10의 권장 13/16이 각각 10/20으로 생성된다.
- 실패경로: 단위 10 상품에 26을 입력하면 화면과 서버가 같은 경고로 저장을 막는다.
- 경계값: 단위 10과 박스입수 6은 최소공배수 30 단위로 생성된다.
- 일관성: 배대지 화면 저장 → 상품마스터 읽기 → 발주안 → 저장된 Draft까지 `bundleUnit`이 유지된다.
- 캐시: 원장 저장 성공 직후 상품마스터 발주 스냅샷 캐시가 무효화된다.
- 회귀: 기존 원장값이 없는 상품, 사용자 제외, 예산 배분, 수동 추가·제거 흐름이 유지된다.
- 안전: 테스트와 배포 검증 중 실제 주문·결제·재고·가격 외부 쓰기를 실행하지 않는다.
