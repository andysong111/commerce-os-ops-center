# 온돌패스 입고현황 자동확인 계획 (2026-11-21)

## 목표

업무센터의 `11-2. 온돌패스 입고현황 확인`에서 확정된 바코드 파일의 신청번호만 조회하고, 온돌패스 품목별 `입고` 상태를 발주차시 4단계 입력값으로 안전하게 준비한다. 실제 재고 입고확정은 사용자가 OPS Center에서 확인 후 누른다.

## 검증된 입력 계약

- 기준 발주차시: `fast-purchase-draft:5cabcbeeffd1b884a074`
- 완료 근거: 신청번호 8건, 102개 원본 행, 101개 B-code
- 온돌패스 품목 식별자: `신청번호 + 행번호`
- 입고 완료 신호: 품목 수량 셀의 별도 `입고` 표식
- 2026-11-21 관찰값: 52행 입고, 49행 대기, 1행 폐기
- 현재 온돌패스 표시 합계 9,677개와 OPS 주문 합계 9,672개는 5개 차이가 난다. 주문번호 매칭은 정상이며, 신청번호 `673626` 6행 `BCE6-3`이 주문 10개·입고 15개인 초과 입고다.

## 수용 기준

1. 정상: 완료 근거의 신청번호/행번호/주문번호와 온돌패스 관찰값이 일치하면 B-code별 실제 입고수량을 계산해 4단계 입력칸에 준비한다.
2. 수량 차이: 주문보다 적으면 `부족 입고`, 많으면 `주문보다 많이 입고`로 분류하고 실제 감지수량을 자르지 않는다. 수동 입력도 같은 규칙으로 주문수량 미만·초과를 허용한다.
3. 실패: 누락·중복·주문번호 불일치·알 수 없는 상태·근거 해시 변경은 해당 관찰을 차단하고 원인을 표시한다.
4. 경계: 같은 관찰 재전송은 중복 기록하지 않으며, 이미 입고로 본 행이 대기로 되돌아가면 차단한다.
5. 스케줄: 1~24시간 간격, 1~48회 범위로 반복하며 모든 근거 행이 입고되면 자동 종료한다. 최대 횟수 도달·폐기/주문 매칭 실패·로그인 만료는 이력에 남긴다.
6. 안전: 관찰은 재고 원장을 직접 변경하지 않는다. 사용자가 4단계 `입고확정` 또는 `전체 정상입고 처리`를 확인해야 원장/Product Master/Shopling 후속 처리가 실행된다.
