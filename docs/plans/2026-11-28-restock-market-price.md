# 입고알림 구매처 가격 비교

운영자가 입고알림 신청에서 ‘최저가 구매처를 문자에 추가’를 선택하면 해당 B코드 옵션의 판매가와 구매 링크를 미리 볼 수 있다. 신청에는 선택 여부만 저장한다.

- 업무센터 PC가 샵플링 A4의 ‘상품이 등록된 쇼핑몰 보기’를 읽는다. 각 결과의 샵플링 상품코드를 확인하고 도매꾹·오너클랜·카페24·스마트스토어의 등록 계정과 판매중 상태를 대조한다.
- 몰판매가에 해당 B코드의 옵션 추가금을 반영해 단가를 비교한다. 배송비·최소 구매수량·주문 수량별 할인은 비교 대상에서 제외한다. 동가일 때는 카페24, 도매꾹, 오너클랜, 스마트스토어 순으로 고른다.
- 발송 준비 시 최근 2분 이내의 조회 결과를 사용한다. 확인 대기 중에는 재조회하고, 조회 기한 초과·불완전한 대조·후보 없음은 기본 입고알림으로 처리한다.
- 검증은 네 마켓 각각의 선정, 품절·삭제·타 계정 제외, 옵션 추가금에 따른 순위 변경, 조회 누락, 링크 중복, 모바일 미리보기, 샵플링 운영 계정의 읽기 전용 대조 순으로 진행한다.
