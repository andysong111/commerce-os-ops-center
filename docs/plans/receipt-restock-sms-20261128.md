# 고객 입고알림

## 신청과 발송

- Ops Center의 입고·창고 → 고객 입고알림에서 고객이 요청한 옵션 B코드와 휴대폰 번호를 등록한다. 기본 문구를 수정할 수 있고, 카페24에 연결된 도소매사우루스 상품을 조회해 링크를 채운다.
- 원구매처가 있으면 도매·소매 마켓의 상품 링크 또는 마켓명과 상품번호를 입력한다. 둘 다 입력해도 된다. 고객에게는 등록한 원구매처 정보와 도소매사우루스 링크가 함께 간다.
- 가격 비교 안내는 고객 동의를 기록하고 같은 옵션·수량·배송 조건의 가격을 확인한 경우에 선택한다. 24시간 이내 확인한 자사몰 가격이 더 낮고 발송시간과 무료수신거부 번호 조건을 충족하면 두 가격을 표시한다. 기본 안내에는 가격을 확인할 수 있는 링크를 넣는다.
- 6단계의 같은 입고번호와 B코드에서 입고 수량이 양수이고 판매중 전송 완료 기록이 있어야 발송 대기 상태로 바뀐다. PC는 발송 직전 자사몰에서 해당 옵션을 구매할 수 있는지 확인한다. 발주차시 화면에서 신청·대기·발송·확인 필요 건수를 확인할 수 있다.
- 샵플링 API 매뉴얼에서 SMS 발송 API 사양을 확인할 수 없어 로그인된 업무용 PC의 G6 SMS관리 화면과 실제 발송내역을 사용한다. 샵플링 등록 발신번호로 보내며 90바이트 이내는 1건, 장문은 3건이 차감된다.

## 운영

초기 설정은 발송 꺼짐이다. 샵플링 문자 설정에서 운영자 시험 모드를 저장한 뒤 운영자가 지정한 휴대폰에 시험 문자 한 건을 보낼 수 있다. 시험에는 실제 입고 신청이 필요하지 않으며 샵플링 단문 한 건이 차감된다. 같은 발신번호의 G6 발송 성공 기록이 생기면 고객 자동 발송을 켤 수 있다. PC 중단 후에는 저장된 신청을 이어받는다. 발송 버튼을 누를 수 있는 상태에 들어간 신청은 발송내역으로 확인하며 결과가 불분명할 때 재발송하지 않는다.

신청은 운영자만 조회할 수 있고 목록에는 전화번호 끝 네 자리만 표시한다. 발송 성공이나 신청 취소 때는 전체 수신번호를 지운다. 운영자 설정과 PC 자격증명은 비공개로 관리한다.

전용 PC에서 샵플링 로그인이 만료되면 업무센터의 기존 인증 절차를 사용한다. 운영자가 카카오톡 보안문자를 확인하면 같은 대기 건을 이어받는다. 발송 여부는 G6 완료건 조회에서 발송 월과 수신번호로 검색한 뒤 발신번호·본문·시각까지 대조한다.

업무용 PC는 샵플링 로그인을 먼저 확인한다. 보안문자가 필요하면 해당 시험 또는 고객 신청을 대기열에 돌려놓고 같은 인증 요청의 결과를 확인한다. 휴대폰에는 숫자 접수, PC 응답 지연, 로그인 완료 또는 인증 종료가 표시된다. 샵플링이 예상 밖의 안내창을 띄우면 입력한 답의 처리를 종료하고 PC에서 확인한다. 독립 배포되는 43121 업무센터에는 기존 로그인 패치에 이어 `local-agent/mobile-work-center/shopling-captcha-result.patch`를 적용한다. 입고알림도 송장출력과 같은 PC의 3초 로그인 확인 주기를 사용한다. 문자 처리기의 응답 시간이 지나도 진행 중인 인증은 한 번만 수행한다. PC 업데이트 시 `local-agent/src/shopling-mobile-login-monitor.mjs`를 복사하고 `shopling-pc-login-monitor.patch`를 이어서 적용한다.

첫 시험의 발송 결과를 기다리는 동안 해당 시험 건에 고객 자동 발송 전환을 예약할 수 있다. 지정한 시험이 같은 발신번호로 성공해야 모드가 바뀐다. 예약 후 발송 설정을 다시 저장하거나 시험 신청을 취소하면 예약을 해제한다.

## 검증과 운영 지표

격리된 데이터베이스에서 입고·전송 증빙, 다른 옵션 차단, 중복 신청·동시 발송·권한 제어를 확인한다. 브라우저 검사에서는 모바일 신청, 원구매처 링크·상품번호, 품절 옵션 차단, G6 단일 수신자 입력을 확인한다. 고객 문자를 보내는 운영 시험은 발신자 본인 한 건부터 진행한다.

목적은 품절 시 구매 의사를 밝힌 고객의 재방문이다. 첫 운영 검증에서 신청 상품과 문자 링크의 옵션 일치, 수신 여부 및 실제 차감 건수를 확인한다. 잘못된 옵션이나 중복 발송이 확인되면 자동 발송을 끄고 해당 신청의 G6 원본 기록을 대조한다.

운영 배포 후 입고·창고 카드, 발주차시 6단계의 신청 내역, 실제 컨트롤러 옵션의 자사몰 상품 연결과 업무용 PC의 운영 서버 접속을 확인했다. 운영 DB에 기록된 마이그레이션 버전은 20261128010900이다. 초기 검증 시 고객 문자 발송은 0건이었다.
