# 상품출시 SEO 필수 포함 키워드 구현 기록

기준일: 2026-11-25
상태: 구현·검증 완료

## 목표

상품출시 진행관리의 상품상세에서 상품명용·검색어용 필수 키워드를 각각 콤마로 입력하고, 신규 SEO 대량등록과 90일 휴지 뒤 물갈이 재등록의 새 SEO RUN에 동일하게 적용한다.

## 수락 기준

1. 상품상세에 두 입력칸이 보이고 저장 후 서버 재조회에서도 값이 일치한다.
2. 상품명 필수 키워드는 새 SEO RUN 입력에 고정되며 STEP 3 확장 seed로 우선 사용된다.
3. 검색어 필수 키워드는 확장 seed로 사용하지 않는다.
4. 상품명 필수 키워드가 1개면 모든 상품명에 넣고, 2개면 제목 길이와 기존 다양성 검사 범위에서 두 키워드 각각의 반영 마켓 수를 우선한다. 3개면 29개 쇼핑몰 상품명에 나눠 쓴다. 각 키워드는 전체 상품명에서 한 번 이상 실제 재료로 사용되어야 한다. 검색어 필수 키워드는 모든 마켓의 공통 검색어 10개에 포함된다.
5. 금지어, 키워드 개별 30바이트 초과, 상품명 필수 키워드 3개 초과, 검색어 필수 키워드 10개 초과를 차단한다. 상품명마다 기존 30~50바이트 조건을 적용한다.
6. 기존 상품명 다양성, 검색어 정확히 10개, Shopling 등록 payload 계약을 보존한다.
7. 정상·누락 입력·중복·한도 초과·금지어·신규/물갈이 공통 경로를 회귀시험하고 해당 테스트를 CI에 연결한다.

## 검증 결과

- 필수 키워드·상품상세 관련 집중 회귀시험 20/20 통과
- SEO 제목 재고 CI와 동일한 통합 회귀시험 124/124 통과
- `npm run typecheck` 통과
- 변경 파일 ESLint 오류 0건(기존 미사용 변수 경고 1건만 유지)
- `npm run build` 통과 · Next.js 126개 정적 페이지 생성 완료
- 운영 Supabase 환경변수가 없는 독립 작업공간이라 브라우저에서 실제 상품을 불러오는 입력칸 검증은 수행하지 못했다. 저장·재조회와 29개 상품명/검색어 10개 강제 포함은 회귀시험으로 검증했다.

## 안전 경계

- 이번 변경은 내부 상품출시 재료와 SEO RUN 생성 규칙만 바꾼다.
- 실제 Shopling 등록, 마켓전송, 물갈이 품절·삭제는 실행하지 않는다.
- 이미 생성된 RUN은 당시 저장된 입력 스냅샷을 유지하고, 수정된 필수 키워드는 이후 새 RUN부터 적용한다.

## 상품명 키워드 분배 후속 변경

- AAA450의 `MBTI 키보드 키링,키보드키링,클리커`는 조합 시 47바이트여서 기존 저장에서 차단됐다. 이번 규칙은 합계 43바이트 제한을 제거하고 필수 키워드와 발굴 키워드를 기존 상품명 후보 선택에서 함께 조합한다.
- 직접 상품명 생성과 V11 희소 후보 복구 모두 전체 상품명에서 필수 키워드 사용을 검증한다. 필수 키워드가 누락된 결과는 FINAL로 보내지 않는다.
- 저장·생성 회귀 사례는 `tests/seoRequiredKeywords.test.mjs`에서 검증하며 Product Launch Tracker CI와 SEO Title Inventory Ledger CI가 실행한다.
- 상품명 필수 키워드는 단어 내부 공백을 제거하고 검색어 필수 키워드는 내부 공백을 보존한다. 두 입력 모두 쉼표 앞뒤 공백과 빈 항목을 제거한다. 검색어 내부 공백은 Shopling의 29개 마켓용 후적용 계획에서도 보존한다.
