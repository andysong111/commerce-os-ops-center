# AI 사우루스 상품별 이미지 검수

AI 사우루스에서 성공한 OPS 제작 작업은 같은 상품에 상세페이지 이미지와 대표·부가 이미지의 식별자를 함께 연결한다. 역할과 소유자가 일치하는 최종 파일만 연결한다. 기존 검수·비용 확인과 상품 상세페이지 URL 승인 절차를 사용한다. 다른 탭이 상태 확인을 먼저 끝냈으면 이전 탭의 다음 조회에 서버에 저장된 결과를 제공한다.

OPS의 이미지 검수는 상품별 대표 1장과 부가 4장을 선택해서 보고, 세로 상세페이지를 가로폭에 맞춰 스크롤한다. 오래된 작업에 대표·부가 이미지 기록이 없어도 상세페이지는 검수할 수 있다.

AAA496은 이미 완료된 결과의 이미지 6장이 같은 제작 작업에 속함을 확인한 뒤 이미지 검수에 연결한다. 이 작업은 기존 JPG를 사용하며 상품출시 진행관리의 URL은 승인 과정에서만 저장한다.

AI 사우루스의 CI에서 같은 작업의 파일만 반환하는지 검증한다. Commerce OS의 Product Launch Tracker CI에서 상품별 결과 저장, 예전 조회의 상태 동기화, 상세페이지 URL 승인 범위를 검증한다.
