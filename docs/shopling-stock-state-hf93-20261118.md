# Shopling 재고상태 HF93 — 클릭 직전 선택 영수증과 빠른 경고 복구

## 실제 증거

- v0.6.54 실제 42건 실행은 37건까지 진행한 뒤 `A21 단품 goods key 119577 · 가격조정 원본 검색 제출 → 전체 정확일치 행 선택`에서 오래 머물렀다.
- Shopling A21 목록의 결과 행은 선택되지 않은 상태였고, `수정 전송할 자료를 선택하여 주세요.` 경고가 표시됐다.
- 해당 문구는 가격을 바꾸는 단계가 아니다. 재고상태 전송이 가격전송에서 검증된 A21 상품 원본 검색·정확행 선택기를 재사용하면서 남은 내부 명칭이다.

## 확인된 원인

1. A21 작업기는 검색 결과의 정확 goods key 행을 선택하고 선택 건수를 확인했다.
2. 그 뒤 기존 팝업 안전점검과 `POPUP_OPENING` 상태 영수증 저장을 기다렸다.
3. 빨간 `상품 수정전송`은 Chrome 신뢰 클릭으로 실행했지만, 이 클릭 경계에서는 행 선택을 다시 확인하지 않았다.
4. 2~3 사이에 Shopling 목록이 다시 그려져 선택이 풀리면 빨간 버튼은 눌리지만 팝업 대신 선택 자료 없음 경고가 열렸다.
5. 기존 코드는 경고를 별도로 식별하지 않아 실제 팝업을 최대 8초 기다리고, 구형 단품 복구기가 6초 뒤 목록 선택부터 다시 시도했다. 따라서 한 건의 선택 실패가 전체 배치 속도를 크게 낮췄다.

## 변경

- 확장 버전을 `0.6.55`로 올린다.
- 정확행 선택 건수와 총 조회 건수를 신뢰 클릭 요청에 포함한다.
- 빨간 버튼 직전에 현재 A21 최상위 프레임의 MAIN world에서 정확 goods key 행을 다시 찾는다.
- 기대 행 수가 다르거나 전건 선택이 3회·240ms 안에 안정화되지 않으면 빨간 버튼을 누르지 않고 재시도 가능한 실패로 끝낸다.
- 정확한 Shopling 선택 자료 없음 경고는 Chrome dialog 영수증으로 확인해 자동으로 닫고, 8초 팝업 대기 없이 해당 B코드만 즉시 재시도 대상으로 남긴다.
- 정확한 새 팝업이 이미 확인된 경우는 HF92 정책대로 그 팝업이 외부 실행 영수증이며 다시 클릭하지 않는다.
- 진행 문구의 `가격조정 원본`을 `A21 상품 원본`으로 변경한다. 가격 필드는 변경하지 않는다.
- B코드 한 건씩 직렬 처리와 정확 팝업 안의 원본 파란 전송 실행·처리화면 영수증 기준은 변경하지 않는다.

## 운영 주의

- 실행 중인 v0.6.54 42건 배치에는 확장을 교체하지 않는다.
- 선택 자료 없음 경고가 떠 있는 현재 실행은 최종 완료·실패 집계가 끝날 때까지 외부 재클릭하지 않는다.
- v0.6.55 설치 전 과거 실패 건을 무조건 재실행하지 않는다. Shopling 처리화면이나 기존 접수 영수증이 있는 건은 먼저 대조한다.
