# SEO 원클릭 마켓전송 자동 재연결 (2026-11-13)

## 목표

`오늘 자동운영 1번 실행`이 SEO 준비와 Shopling 등록에서 끝나지 않고, 동일 작업의 검증된 `goods_key`로 마켓전송 완료까지 자동으로 이어진다.

## 확인된 문제

- 최초 확장프로그램 인계 성공 직후 Commerce OS가 재연결 토큰을 삭제했다.
- Shopling 등록을 기다리는 동안 확장프로그램 서비스 워커나 A18 연결이 끊기면, 페이지를 다시 열어도 동일 작업을 자동 재인계할 수 없었다.
- Shopling 등록 성공 상품은 다시 등록하면 안 되므로 기존 `goods_key`만 사용해야 한다.

## 변경 원칙

- 동일 오케스트레이션과 동일 토큰을 완료될 때까지 브라우저에 보관하고 15초마다 안전하게 재인계한다.
- 버튼을 누를 때 확장프로그램 응답이 잠시 없어도 Shopling 서버 작업과 오케스트레이션을 먼저 보존하고, 연결이 돌아오면 추가 클릭 없이 이어간다.
- 로컬 토큰이 사라진 활성 작업은 사용자 소유권과 에이전트 lease를 확인한 뒤 토큰만 교체한다.
- 살아 있는 에이전트 lease는 절대 빼앗지 않는다.
- 만료된 `market_running` 작업만 `market_ready`로 되돌려 재개한다.
- Shopling 상품등록과 SEO 생성은 재실행하지 않는다.
- 완료·예외·취소 작업은 다시 인계하지 않는다.

## 검증 결과

- 정상 인계와 15초 주기 동일 토큰 재인계 계약을 확인했다.
- Shopling 업로드 대기 중 브라우저 연결 복구 경로를 확인했다.
- 활성 lease 보호, 만료 lease 복구, 완료 작업 재전송 차단 정책 테스트가 통과했다.
- 상태와 lease가 동시에 일치할 때만 토큰을 교체하도록 경쟁 상태를 차단했다.
- 원클릭·마켓전송 관련 회귀 테스트 36개, TypeScript 검사, 변경 파일 ESLint가 통과했다.
- Next.js 프로덕션 빌드 산출물(`.next/BUILD_ID`) 생성을 확인했다.
- 전체 저장소 ESLint는 이번 변경과 무관한 기존 오류가 남아 있어 별도 정리가 필요하다.

## 실제 계정 관리자 주소 복구 (v0.3.45)

- 2026-11-13 실제 계정은 `a.shopling.co.kr` 접속 직후 `kt.shopling.co.kr`로 이동했다.
- v0.3.44의 Commerce OS handoff와 서버 재연결은 성공했지만, A18 실행기와 background 제어 탭 판정이 `a.shopling.co.kr`만 허용해 18개 기존 `goods_key`가 `market_ready`에 머물렀다.
- v0.3.45는 검증된 관리자 주소 `a.shopling.co.kr`, `kt.shopling.co.kr`만 명시적으로 허용한다. 임의의 `*.shopling.co.kr` 전체를 관리자 화면으로 넓히지 않는다.
- 자동 에이전트가 V0343 guard를 검사하면서 V0330 guard를 기록하던 불일치도 바로잡아 같은 페이지에서 중복 polling이 생기지 않게 했다.
- 이 복구는 SEO 생성이나 Shopling 상품등록을 재실행하지 않는다. 기존 오케스트레이션의 3상품·18개 `goods_key`를 그대로 이어서 마켓전송한다.
- 새 확장 설치·새로고침 뒤 서버 상태가 `market_claimed`/`market_running`으로 전환되고 최종 `completed` 또는 `completed_with_exceptions`가 될 때까지 실제 운영 완료로 보고하지 않는다.

## A19 실패건 금지키워드 자동학습 (v0.3.46)

- 제공된 Shopling API 매뉴얼에는 A19 `쇼핑몰상품등록(실패건)` 조회 계약이 없다. 따라서 상품·마켓전송은 기존 검증 API/원장을 유지하고, A19 조회만 로그인된 `a.shopling.co.kr` 또는 `kt.shopling.co.kr` 관리자 화면을 읽는 하이브리드 방식으로 처리한다.
- 마켓전송 원장이 종결된 뒤 A19를 오늘 날짜·100건으로 정확히 한 번 조회한다. 검색 폼·날짜·행 개수·파싱 시각 영수증이 없으면 원클릭 작업을 완료하지 않고 A19 감사만 재시도하며, 상품이나 마켓전송은 다시 실행하지 않는다.
- 서버는 현재 오케스트레이션의 검증된 `goods_key`만 허용하고, `등록이 불가능한 단어[... ]가 상품명/검색어에 포함`된 실패만 추출한다. 카테고리, 커버 이미지, 토스 옵션 등의 실패는 금지키워드로 저장하지 않는다.
- 추출어는 사용자별 `SEO_PROHIBITED_KEYWORD_POLICY_V1` 원장에 누적하고 독립 readback을 거친다. 이후 신규·이전상품 SEO RUN은 이 서버 정책을 항상 병합한다.
- 2026-11-13 현재 A19 실화면 27건에서 확인된 자동학습 대상은 `넥밴드` 1개다. 현재 18개 `goods_key`의 마켓전송 시도 완료와 채널별 성공은 구분하며, 실패 채널을 성공으로 승격하지 않는다.
