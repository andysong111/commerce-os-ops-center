# 5-1 실제원가 발주안 재계산 — 2026-10-28

## 문제

- 대략 재고를 저장하고 발주안을 재계산해도 5-1에서 확인한 실제 위안단가·중국내 운임이 발주 우선순위와 예산 배분에 다시 들어가지 않았다.
- 재계산 직전에 입력한 중국옵션·링크·원가·운임이 교체 Draft로 이어지지 않을 수 있었다.
- 상품대금이 예산을 초과하면 5-1 진입 자체가 막혀, 실제 원가를 얻어 재계산할 수 없는 순환 문제가 있었다.

## 변경

- 5-1 저장 Draft에서 판매자 합배송 운임을 그룹 총수량으로 나눈 실제 착지원가 스냅샷을 만든다.
- 실제원가는 검증원가·도매가 추정·내부 추정보다 먼저 사용하고, 저장 전후 지문이 다르면 계산을 중단한다.
- 재계산 요청이 현재 표의 입력값을 먼저 저장하고 교체 Draft에 중국옵션·링크·위안단가·운임·주문번호·메모를 승계한다.
- 5-1의 모든 SKU 단가가 저장되면 자동으로 발주안을 재계산한다. 예산 초과 시에도 5-1 원가수집은 열 수 있고, 5-2 장바구니 단계만 예산 안에서 허용한다.
- 현금 배분은 `4만원 충족 월 수 → 월평균 매출 → 상승세 → 종합점수` 순서를 유지하며, 명시적 사용자 고정수량만 먼저 보호한다.

- 발주·재고·예산 관련 회귀 테스트 326개 통과.
- 변경 파일 ESLint 및 TypeScript 검사 통과.
- Next.js 프로덕션 빌드 통과(정적 페이지 124개 생성).
