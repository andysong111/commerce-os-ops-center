# Shopling 품절 HF35 (`v0.6.3`) — 2026-10-29

## Incident and confirmed regression

- 운영자가 `BCB6-2` 자동처리를 실행했지만 A6 총 조회수는 8건인데 worker가 9행을 읽었다며 외부 변경 전에 중단했다.
- HF19까지의 A6 결과행 필터는 정확 B코드와 상품/옵션 식별자 형태를 모두 요구했다.
- HF33 `v0.6.1`에서 입력값 속 B코드도 읽도록 범위를 넓이면서 `a6RowsFromDocumentHF19`가 B코드 일치만 확인하도록 바뀌었다. 그 결과 B코드를 담은 검색조건 행도 상품 결과행으로 집계됐다.
- HF33의 A6 사전 설정은 `2022-01-01`, 공통 검색정책은 `2013-09-12`를 사용해 동일 검색 안에서 날짜 기준도 충돌했다. HF34 `v0.6.2`는 숨겨진 날짜 입력칸 탐지만 보완했으며 이 두 회귀는 고치지 못했다.

## Change

- HF35 `v0.6.3`은 A6 사전 설정과 공통 검색정책의 시작일을 모두 `2023-01-01`로 통일하고 종료일은 KST 오늘로 계산한다.
- 정확 B코드가 있어도 Shopling 결과 체크박스와 `goodsKey/optionId` 식별자가 함께 없는 행은 A6 상품 결과에서 제외한다. 따라서 검색조건 행은 총 조회수 비교에 포함되지 않는다.
- Commerce OS는 `v0.6.2` 이하 실행을 차단하고 다운로드·안내를 `v0.6.3`으로 올린다.
- 옵션상태 API의 수량 보존, `SOLD_OUT -> C`, `ON_SALE -> B`, A21 전송, 실패/불확실 자동 재시도 금지는 그대로 유지한다.

## Verification

- 실제 장애 fixture `검색조건 1행 + BCB6-2 실제 상품 8행 + 유사코드 1행`에서 정확히 8행만 선택되는 회귀 테스트를 추가했다.
- Inventory Stock Control CI 대상 87건 통과.
- 변경 파일 ESLint 통과, `tsc --noEmit` 통과.
- `next build --webpack` 프로덕션 빌드 통과.
- 빌드된 서버의 `/api/shopling-stock-state-sync/download-hf35?verify=1` 응답에서 `v0.6.3`, `20230101`, 검색조건 행 제외를 확인했다.
- 실제 ZIP을 풀어 worker를 검사한 결과 `20230101` 두 경로가 각각 1개, 상품행 identity guard 1개였고 `20130912`와 `20220101`은 없었다.
