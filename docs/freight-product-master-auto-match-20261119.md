# 배대지 신청서 상품마스터 자동매칭 작업 기록 (2026-11-19)

## 목표

- 수동 붙여넣기와 온돌패스 확장 가져오기 모두 실제 커머스OS 상품마스터에서 B코드, 모델번호, 모델명을 자동 입력한다.
- 같은 1688 상품에 옵션이 여러 개면 중국 옵션이 정확히 일치하는 SKU만 적용한다.
- 애매한 후보는 추정하지 않고 미매칭/확인 필요로 남긴다.

## 매칭 계약

1. 신청서 `상품상세url`의 1688 offer ID와 상품마스터 SKU `supplierUrl`의 offer ID를 정확히 대조한다.
2. 신청서에 옵션이 있으면 상품마스터 `chinaOptionName`과 정규화 후 정확히 일치해야 한다.
3. 신청서 옵션이 없고 해당 offer ID의 활성 B코드 SKU가 정확히 하나일 때만 적용한다.
4. 수동 적용은 B코드, 모델번호, 상품명의 정확 일치만 허용하며 복수 SKU면 자동 적용하지 않는다.
5. 상품마스터 비밀키는 서버 API에서만 사용하고 브라우저 코드에는 노출하지 않는다.
