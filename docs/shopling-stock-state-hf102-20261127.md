# 옵션과 상품 판매상태의 마켓 전송

2026년 11월 27일 BCD8-1·BCD8-2 판매재개 실행에서 OPS에 옵션 접수 2건이 기록됐다. 도매꾹 상품 63541344에는 PS4·PS5 재고가 각각 999개로 보였고 상품 상단에는 ‘진열하지 않음’이 표시됐다. 기존 다옵션 경로는 옵션 전송만 계획했다. 도매꾹의 진열 설정이 바뀐 경위는 이 화면으로 확정할 수 없다.

## 적용 순서와 검증 범위

- 전송 전 각 B코드를 실제 샵플링 상품번호와 전체 옵션에 대응시켜 입력 전후 상태를 계산한다.
- 같은 상품에 속한 옵션 작업은 순차 처리한다. 필요한 옵션 전송의 원본 접수를 확인한 뒤 해당 상품의 판매상태를 전송한다. 부분 품절, 마지막 옵션 품절, 전체 품절에서 한 옵션 복구, 혼합 입력, 판매종료 제외와 불명확한 접수를 검증한다.
- 운영 검증은 읽기 전용 사전조회와 확장 연결로 진행한다. 실제 마켓 접수는 운영자가 시작한 전송에서 확인한다.

## BCD8 읽기 전용 검증

실제 읽기 전용 대조에서 두 B코드는 동일한 샵플링 상품번호 120867–120872에 연결됐다. 6개 상품과 PS4·PS5 옵션 12개가 모두 판매중(B)이었다. 샵플링에 이미 B가 기록된 이 상태에서도 두 옵션의 접수 뒤 6개 상품번호 전체에 상품 판매중 전송을 계획한다. 마켓의 진열 설정이나 성공 여부는 이 조회에서 제공하지 않는다.
