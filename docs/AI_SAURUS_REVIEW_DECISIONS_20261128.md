# AI 사우루스 검수 결정과 B코드별 이미지 저장

## 적용 범위

- 검수 승인 시 같은 제작 영수증의 상세페이지 1장, 대표 1장, 부가 4장의 호스팅 URL과 상세페이지 HTML을 해당 상품에 저장한다. 기존 SEO 대량등록 입력에서 이 재료를 사용한다.
- B코드와 전체 이미지가 확인돼야 승인할 수 있다. 상품이나 이미지 자료가 제작 후 수정됐으면 승인 전에 확인한다. 검수 결정을 먼저 저장하고 상품의 이미지 주소 6개와 HTML을 다시 읽어 확인한 뒤 승인 완료로 표시한다.
- 재시도는 최초 시도 뒤 한 번이다. 입력값을 다시 준비하거나 다른 상품과 묶어 선택해도 실행 횟수를 유지한다. 재시도 준비에서 크레딧을 소모하지 않는다.
- 거절은 원래 작업에 계속 기록된다. 같은 상품 ID 또는 B코드로 다른 작업을 시작할 수 없다. 직접 제작 URL 입력은 이 상태에서 이용한다. 일반 상품출시 진행관리의 승인 외 자료를 보존한다.

## 검증

- 대표 사례 AAA496의 실제 B코드는 BDG6-2다. 검수 화면과 저장 경로를 확인하는 동안 이 운영 상품에 승인, 거절, 재시도 요청을 보내지 않는다.
- Product Launch Tracker CI에서 승인과 SEO 등록 입력, 두 번째 시도 이후 차단, 거절 이후 재준비 차단을 검증한다.
- 로컬 Chrome에서 상품 한 건의 승인, 재시도 준비 및 소진 상태, 거절 취소와 확정, 수동 URL 제출을 확인했다. 테스트 API로 클릭과 저장 요청 대상을 대조했다.
- 서비스 역할 전용 PostgreSQL 함수로 같은 상품 ID 또는 B코드의 동시 작업 묶음을 차단한다. 읽기 전용 충돌 조회, 버전 검사, 같은 작업 재시도, 다른 소유자 분리를 검증한다.
