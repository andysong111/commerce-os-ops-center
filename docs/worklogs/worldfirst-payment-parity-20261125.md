# 발주차시 1688 실결제와 콰징바오 수수료

- 11월 4일 바코드 원본 102줄, 101 B-code, 9,672개, 58개 주문번호. 기존 금액은 같은 B-code의 초안 16,280개를 합산했고 화면에는 56개 주문번호가 표시됐다.
- 온돌패스 단가 합계 19,666.43위안은 상품 참고액이다. 상품대금·중국내운임·1688 서비스비 및 환불 반영액의 증거는 1688 결제 자료에서 확인한다.
- 금액 등록은 바코드 원본과 주문번호·B-code·수량을 정확히 대조하고 영수증 총액과 행의 합을 비교한다. 바코드 지문, 요율, 내부환율, 위안 분 단위 금액을 버전이 있는 결제 기록에 저장하고 동일 요청은 한 번만 차감한다.
- 주문 원장이나 바코드 완료 기록만 있고 결제 증거가 없으면 예산 잔액과 입고 원가를 검증 대기로 둔다. 결제원가는 1688 실결제 + 월드퍼스트 콰징바오 0.8%의 내부환율 환산액이다. 배송대행 마감에는 실제 비용을 더한다.
- 증거: [WorldFirst 콰징바오 수수료 안내](https://www.worldfirst.com/kr/help-center/faqs/1688-world-pay/), 11월 19일 캡처의 59,893원 → 479원 및 20.04달러 → 0.16달러.
