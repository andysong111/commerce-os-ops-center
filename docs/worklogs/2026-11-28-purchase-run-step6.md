# 발주차시 6단계 입고 후 처리

- 가격 미리보기·실행·재개는 선택 차시의 확정 입고를 사용한다. 같은 B코드의 이전 확정 원가는 가격 보호 계산에 사용한다. 동일 상품번호의 차시 밖 옵션은 보류한다.
- 입고확정과 6단계 이어가기는 같은 전송 원장을 쓴다. 수량·판매 이력·매핑을 확인한 B코드는 기존 판매중 상태도 전송한다. 원장 시작 기록과 서명된 계획을 확보한 뒤 B코드 하나씩 진행한다.
- 원본 접수증 전체가 일치하면 접수 완료로 표시한다. 마켓 실패 표시와 접수 증빙 부족은 보류 사유로 확인한다. 창이 끊긴 경우 원래 확장 결과를 다시 읽을 수 있고, 31분이 지난 시작 기록은 확장의 작업 종료 확인 후 보류할 수 있다. 보류 기록은 같은 전송을 다시 시작하지 않는다.
- 회귀 검증은 `tests/monthly-price-persistence.test.mjs`, `tests/receipt-on-sale.test.mjs`, `scripts/receipt-on-sale-browser-check.mjs`와 Monthly price one-click verification 워크플로에서 실행한다.
- 운영 확인은 11월 차시 화면을 조회한다. 실제 판매가 적용과 마켓 전송은 입고 증빙과 원가를 확정한 뒤 운영자가 실행한다. SEO 대량등록과 물갈이 편입은 후속 작업이다.
