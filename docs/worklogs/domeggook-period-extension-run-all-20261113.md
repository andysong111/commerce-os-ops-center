# 도매꾹 전체 즉시실행·everysale999 복구 (2026-11-13)

## 변경

- 로컬 도매꾹 관리 화면에 `전체 즉시실행`을 추가했다.
- 저장된 계정을 순차 실행하고, 한 계정 실패가 다음 계정 실행을 막지 않도록 격리했다.
- 전체 실행 전 계정·연장일을 확인창에 표시하고, 종료 후 성공·실패 계정 수와 실패 계정을 표시한다.
- Chrome 준비 판정을 `/json/version`뿐 아니라 실제 page target까지 확인하도록 강화했다.
- 로그인 제출 직후 페이지 이동으로 CDP 응답이 사라지던 경합을 막기 위해 클릭을 응답 이후로 지연했다.

## 실제 검증

- `everysale999` 읽기 전용 시험 실행 성공: 로그인 계정 확인, 기간종료 상품 4개 조회, 실제 연장 미실행.
- 도매꾹 집중 테스트 24개 통과.
- TypeScript 검사와 변경 파일 ESLint 통과.
- Next.js Webpack 프로덕션 빌드 통과.

## 안전 경계

- 전체 즉시실행은 로컬 Windows·동일 출처 API에서만 가능하다.
- 실제 실행 전 브라우저 확인을 요구한다.
- 실제 기간연장은 이번 검증에서 실행하지 않았다.
