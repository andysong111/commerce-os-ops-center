# 확정 신규소싱 재계산 복구 — 2026-11-01

## 운영 증거

- 사용자가 명시적으로 고른 신규소싱은 6상품·8옵션이며 자동 소싱엔진 후보 62개는 제외한다.
- 확정 예약의 최신 수량 합계는 139개다. 기존 Draft에는 동일 B-code 중 일부의 과거 수량이 남아 신규소싱 합계가 135개로 표시됐다.
- 잘못된 합계는 `BDB6-3` 10→12개, `BDG6-2` 15→17개가 최신 예약 수량으로 갱신되지 않은 데서 발생했다.

## 변경

- 같은 수동 선택을 재생성할 때 기존 Draft의 수량보다 확정 예약 수량을 우선한다.
- 과거 URL에 옵션 식별자가 없더라도 정확한 8개 콘셉트·창고 선택과 일대일 확정 B-code가 검증되면 저장을 허용한다.
- 콘셉트 중복, B-code 중복, 선택·창고 불일치, 예상 밖 옵션은 계속 실패 처리한다.
- 이 경로는 내부 Draft만 준비하며 1688 주문·결제는 실행하지 않는다.

## 회귀검사

- `tests/purchaseCyclePreflightDraft.test.mjs`에 실제 장애 형태를 추가했다.
- 보존된 과거 수량과 최신 확정 수량이 다를 때 화면 합계와 저장 행이 모두 최신 수량을 사용해야 한다.
- 옵션 식별자가 없는 과거 행은 정확한 일대일 콘셉트·B-code에만 허용하고, 재구성된 옵션이 다르면 차단한다.
