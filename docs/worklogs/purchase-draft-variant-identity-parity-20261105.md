# 신규소싱 옵션 식별자 정합성 복구 — 2026-11-05

## 운영 증거

- 화면에서 확인한 발주안은 97종·9,819개였지만 저장 직전 서버 재검증 결과는 89종·9,695개였다.
- 차이 8종·124개는 사용자가 확정한 신규소싱 8옵션 전체였다.
- 요청 옵션은 `direct-variant-v1:` 이름공간을 사용했고, 확정 예약 생명주기 데이터는 동일 옵션의 원래 키를 보존해 두 값을 문자 그대로 비교하면 누락됐다.

## 변경

- 소싱엔진이 검증한 `direct-variant-v1:` 이름공간만 공유 식별자로 정규화해 요청 옵션과 확정 예약을 일대일 대조한다.
- 알 수 없는 이름공간, 중복 옵션, 하나의 옵션에 둘 이상의 예약이 매칭되는 경우는 계속 실패 처리한다.
- 기존 Draft 저장 안전장치와 주문·결제 비실행 원칙은 유지한다.

## 회귀검사

- 실제 장애 수량인 신규소싱 8옵션·124개가 저장 예정 합계에 그대로 복원되는 검사를 추가했다.
- 지원하지 않는 이름공간과 중복 매칭은 저장을 차단하는 음성 검사를 추가했다.
- 대상 테스트 40개, TypeScript 타입 검사, 변경 파일 ESLint를 통과했다.
