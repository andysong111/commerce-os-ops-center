## 구현

- 배포 화면은 서버 실행원장의 4계정 설정과 날짜별 성공·실패 영수증을 읽는다.
- 운영 화면에서는 계정·시간·연장기간을 조회 전용으로 표시하고, 비밀번호·예약 변경은 로컬 Windows에서만 허용한다.
- 로컬 실행기는 계정별 이력 JSON을 보존하고, 전용 DPAPI 동기화 토큰으로 최근 이력을 멱등 업서트한다.
- 비밀번호와 동기화 토큰은 브라우저·DB·명령행·영수증에 포함하지 않는다.
- 기존 `commerce_operation_runs`를 재사용하므로 새 테이블이나 공개 RLS 정책은 추가하지 않는다.
