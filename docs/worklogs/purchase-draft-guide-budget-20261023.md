# 발주초안 가이드·수동수량 예산 규칙 — 2026-10-23

## 목표

- 발주초안에서 작업 순서를 팝업으로 안내한다.
- 수동 추가 B코드 수량을 사용자 고정수량으로 명확히 표시한다.
- 고정수량 예산을 먼저 확보하고 자동 추천품목에 남은 예산을 배분하는 기존 계산 규칙을 UI와 회귀검사로 고정한다.
- 재계산 대기 또는 실제 위안단가 기준 예산 초과 상태에서 5번 업무와 주문완료 기록을 막는다.

## 수용 기준

- [x] 첫 방문에는 가이드가 자동으로 열리고 이후 `작업 순서 보기`로 다시 열 수 있다.
- [x] 화면 순서는 상품 재고·수량 표 → B코드 수동 추가 → 최종 재계산이다.
- [x] 수동 추가수량은 5개 단위이며 사용자 고정값임을 표시한다.
- [x] 실제 위안단가·운임 반영 후 예산을 다시 검증하고 초과 시 주문완료 기록을 막는다.
- [ ] 관련 테스트·타입검사·브라우저 검증을 통과한다. (코드 검사·타입검사·관련 회귀검사 완료, Production 브라우저 검증 대기)
