# Shopling 재고상태 HF89 작업 기록 (2026-11-17)

## 확인된 장애

- HF86의 신뢰 클릭은 A21 `상품 수정전송`을 눌러 새 팝업 ID까지 확인했다.
- HF84의 파란 전송 로직은 새 팝업의 Chrome 생성·갱신 이벤트를 다시 받아야만 시작했다.
- 이벤트가 누락되거나 이전 팝업이 남아 있으면 새 팝업은 열리지만 파란 전송 버튼 실행이 시작되지 않았다.

## HF89 변경

- HF86이 확인한 정확한 새 팝업 ID를 `A21_EXACT_POPUP_HANDOFF_HF89`로 즉시 백그라운드에 넘긴다.
- 백그라운드는 현재 작업·A21 목록 탭 소유권을 확인한 뒤 그 팝업만 HF84 엔진에 고정한다.
- 기존 HF84의 `상단 전송 종류 선택 → 하단 대상 선택 → Shopling 원본 전송 함수`를 그대로 실행한다.
- `WAIT_A21_RESULT` 단계와 파란 전송 실행 영수증을 모두 확인해야 목록 작업을 성공으로 처리한다.
- 확장 버전은 `0.6.52`, 서비스 워커는 `background-v098.js`, 다운로드 경로는 `/api/shopling-stock-state-sync/download-hf89`이다.

## 검증 결과

- HF86~HF89 및 실행 계획 회귀 26건 통과.
- TypeScript 검사와 변경 파일 ESLint 통과.
- Next.js production build 통과.
- 로컬 다운로드 API가 v0.6.52 ZIP 261,945바이트를 생성했고, manifest·v098·canonical v019/v020 포함을 확인했다.
- 실제 Shopling 상품 전송은 외부 상태 변경이므로 사용자 설치 후 대표 1건으로 최종 확인한다.
