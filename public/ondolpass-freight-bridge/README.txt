Commerce OS 온돌패스 신청서 브리지 v0.2.0

역할
- Commerce OS 배대지 바코드 화면에서 신청서 번호 또는 신청일 범위를 받습니다.
- 로그인된 Chrome의 온돌패스 상세페이지를 읽습니다.
- 수취인 주소·전화번호가 아니라 제품정보 블록과 상품 이미지만 전달합니다.
- 신청일 범위 조회는 온돌패스 신청현황의 조회 주소만 열며 체크박스, 신청서 내용은 변경하지 않습니다.
- 기존 콘텐츠 스크립트 연결이 끊겨도 읽기 전용 스크립트를 상세 탭에 직접 주입해 복구합니다.

설치
1. ZIP 압축을 풉니다.
2. Chrome 주소창에 chrome://extensions 를 입력합니다.
3. 개발자 모드를 켭니다.
4. 압축해제된 확장 프로그램을 로드합니다.
5. 이 폴더를 선택합니다.
6. 온돌패스에 로그인한 상태에서 Commerce OS 바코드 화면을 새로고침합니다.

사용
1. 신청서 번호를 입력합니다.
2. "가져와서 자동 분석"을 누릅니다.
3. 분석된 품목 수와 이미지 수를 확인합니다.

신청일 범위로 사용
1. 신청일 시작일과 종료일을 선택합니다.
2. "기간 신청서 가져와서 자동 분석"을 누릅니다.
3. 조회된 신청서 번호와 분석 품목 수를 확인합니다.

오류가 날 때
- 로그인 안내가 나오면 자동으로 열린 온돌패스 탭에서 로그인한 뒤 다시 실행합니다.
- 이전 버전에서 갱신했다면 chrome://extensions에서 이 확장의 새로고침 버튼을 누르고 Commerce OS 화면도 새로고침합니다.
- 품목 수가 다르면 자동 적용하지 않으므로 신청서 번호와 온돌패스 화면을 확인합니다.
